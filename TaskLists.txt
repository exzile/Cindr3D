# ── ENTITY / DRAWING TOOLS ────────────────────────────────────────────────────
#
# [ ] SKETCH-1.1 SketchFixedSpline — Fusion's fixed/frozen spline type that does NOT
#     deform under constraints (used for imported external curve data, STEP round-trip).
#     No 'fixed-spline' entity type exists. Add entity type that renders as a regular
#     spline but is excluded from the solver (treated like a Fix-constrained entity).
#     Low priority; required for clean STEP/DXF import of spline geometry.
#
# [ ] SKETCH-1.2 BreakLink — Fusion lets you break the associativity of a projected /
#     intersected curve so it becomes a standalone editable entity. We project curves
#     with `linked: true` but there is no action to toggle linked->false. Add a
#     right-click context-menu action (and toolbar button) that clears `linked` on
#     selected projected entities so they can be edited freely.
#
# ── EDITING TOOLS ─────────────────────────────────────────────────────────────
#
# [ ] SKETCH-1.3 Mirror along a picked sketch line — our commitSketchMirror only
#     supports 3 fixed axes (horizontal, vertical, diagonal). Fusion lets you pick any
#     existing sketch line as the mirror axis and reflects the selection across it.
#     Implementation: when the user picks a line entity as the axis, compute the
#     reflection matrix from the line's direction vector (project-reflect-unproject in
#     the sketch plane) and apply it to all selected entity points.
#     File: sketchTransformActions.ts (extend commitSketchMirror); SketchMirrorPanel.tsx
#     (add "Pick Line" step before the commit button).
#
# [ ] SKETCH-1.4 Offset Curves (HIGHEST PRIORITY — currently a SILENT NO-OP) —
#     the toolbar button and hotkey 'O' activate 'sketch-offset', but NO commit handler
#     exists in any commitHandlers file and commitSketchOffset does not exist in the
#     store. The user clicks and nothing happens. Fusion's Offset creates parallel
#     copies of all selected curves at a fixed distance.
#     Implementation:
#       - Lines: translate perpendicular to direction by offset distance.
#       - Arcs/circles: increase or decrease radius by offset distance.
#       - Splines: offset each control/fit point along local normal.
#       - Chain mode: walk tangent-connected curves and offset the whole chain.
#     Engine: add sketchOffsetCurves(entities, distance, side) in
#       engine/geometryEngine/core/sketch/.
#     Store: add commitSketchOffset() in sketchTransformActions.ts.
#     Wire: add 'sketch-offset' case to the commit handler chain (editingHandlers or
#       lineEditingHandlers). Panel: reuse the existing SketchTransformPanel pattern.
#
# [ ] SKETCH-1.5 Break / Split point on curve — 'break' is in the Tool type union
#     (core.ts) but has NO commit handler. Clicking does nothing. Fusion's Break splits
#     a curve at the click point into two separate entities, automatically adding a
#     coincident constraint at the split point.
#     Implementation: raycast to the nearest sketch curve, compute the parametric split
#     position (t value), replace the entity with two entities whose shared endpoint
#     is coincident. For arcs: split at the angle. For splines: split the control
#     polygon. Add a 'break' case to lineEditingHandlers.ts.
#
# ── CONSTRAINTS ───────────────────────────────────────────────────────────────
# [ ] SKETCH-1.6 Smooth constraint (SmoothConstraint.h) — G2 curvature continuity
#     PLUS co-linear curvature vectors at a junction (no twist / curvature direction
#     discontinuity). Different from our existing Curvature constraint which only
#     enforces equal magnitude. Add ConstraintType 'smooth'; solver residuals: match
#     curvature magnitude AND the direction of the curvature vector (osculating circle
#     axis) at the shared endpoint.
#
# [ ] SKETCH-1.7 Horizontal/Vertical Points constraints
#     (HorizontalPointsConstraint.h, VerticalPointsConstraint.h) — constrains two
#     arbitrary (non-adjacent) points to share the same U or V coordinate in the
#     sketch plane. Different from constraining a LINE to be horizontal/vertical.
#     Useful for aligning a point on one entity with a point on a separate entity.
#     Add ConstraintType 'horizontal-points' / 'vertical-points'; solver residuals
#     p1.u == p2.u and p1.v == p2.v respectively.
#
# [ ] SKETCH-1.8 Parametric Pattern constraints
#     (CircularPatternConstraint.h, RectangularPatternConstraint.h) — Fusion's sketch
#     patterns create copies AND a constraint that keeps them synchronized. Editing one
#     copy propagates to all others via the solver. Our sketch patterns (commitSketchRect
#     Pattern / commitSketchCircPattern) copy entities but add no linking constraint.
#     Add ConstraintType 'sketch-rect-pattern' / 'sketch-circ-pattern' whose solver
#     residuals enforce equal spacing between copies and the original. This upgrades
#     sketch patterns from "paste copies" to "live parametric patterns".
#
