# BROWSER QA — OCC-21/22 + 21.4e geometry (NEEDS A HUMAN IN THE LIVE 3D APP)
# ══════════════════════════════════════════════════════════════════════════════
# All logic/math below is tsc-clean + unit-tested (full suite green), but the
# actual OCC kernel geometry was NOT exercisable in the headless test harness.
# These steps verify the on-screen result. Run `npm run dev`, open the Design
# workspace. All tools live in the ribbon DESIGN tab → "MODIFY" dropdown unless
# noted. Each body op needs an OCC SOLID first (Create → Box / Cylinder primitive,
# or a sketch + Extrude). Watch the status-bar message (bottom) and the timeline.
#
# Convention below:  ▶ steps   ✓ expected pass   ✗ failure signature
#
# ── QA-21.4e-A  Silhouette Split — CYLINDER (the headline new feature) ─────────
#   ▶ Create → Cylinder primitive (e.g. r=10, h=30, axis = Z).
#   ▶ MODIFY → "Silhouette Split". In the dialog set Split Type = "Silhouette",
#     Body = the cylinder, View Direction = "Along X axis". Confirm.
#   ✓ The cylinder's curved face is now divided into two halves by two straight
#     vertical seam lines on the ±Y sides (the outline as seen looking down X).
#     Volume/shape unchanged; status: "Silhouette Split: outline imprinted on …".
#     The two new face halves should be independently hover-highlightable.
#   ✗ "no cylindrical/conical silhouette …" (math rejected the view — try a view
#     NOT parallel to the axis) OR no visible seam / unchanged face (BRepFeat
#     imprint failed — capture console warnings beginning "[occSilhouetteSplit]").
#   ▶ Repeat with View Direction = "Along Z axis" (parallel to the cylinder axis).
#   ✓ Expected NO-OP with status "no cylindrical/conical silhouette for this view
#     direction" — a view down the axis has a circular outline, not rulings.
#
# ── QA-21.4e-B  Silhouette Split — CONE ────────────────────────────────────────
#   ▶ Make a cone: sketch a circle, Revolve a triangle, or a Coil/loft — any body
#     with a conical face. (If no cone primitive exists, a Draft on a cylinder
#     face or a revolved profile yields one.)
#   ▶ MODIFY → "Silhouette Split", Split Type = "Silhouette", View = side axis (X/Y).
#   ✓ The conical face gets two SLANT seam lines (following the cone's taper, not
#     vertical) where the outline sits — i.e. the seams converge toward the apex.
#   ✗ As above. Note: for a steep cone viewed near-axially the math may return 0
#     rulings by design (status no-op) — pick a more side-on axis.
#   NOTE for both A/B: this realizes Fusion "FacesOnly". 'solid-body'/'shelled-body'
#     and sphere/torus/freeform are intentionally deferred (status no-op + warn).
#
# ── QA-21.2  Split Face (WAS SILENTLY BROKEN before the TKFeat loader fix) ──────
#   This is the regression check for the TKFeat fix — it returned null on every
#   call until 2026-05-31.
#   ▶ Create → Box. Create a construction plane that cuts through the top face
#     (e.g. an offset XZ plane through the middle).
#   ▶ MODIFY → "Split Face". Pick the box's top face, choose the construction
#     plane as the splitting tool. Confirm.
#   ✓ The top face is split into two faces along the plane intersection line;
#     body volume unchanged; status "Split Face applied".
#   ✗ "Split Face: OCC operation failed …" → re-confirm TKFeat is loading (Network
#     tab should fetch module.TKFeat.wasm at startup; console "[occSplitFace]").
#
# ── QA-21.1  Direct Edit (offset-face / extrude / taper) ────────────────────────
#   ▶ Create → Box. MODIFY → "Direct Edit". Pick a face.
#   ▶ Mode = Offset Face, distance = +5, confirm.  ✓ that face pushes out 5mm
#     (volume grows); status "Direct Edit (offset-face) applied".
#   ▶ Repeat, Mode = Extrude, distance = -3.  ✓ face pulls in (cut), same as a
#     negative offset.
#   ▶ Repeat, Mode = Taper, angle = 10°.  ✓ the picked planar face tilts by 10°.
#   ✗ "Direct Edit … OCC operation failed" or no change → console "[occOffsetFaces]"
#     / "[occDraft]"; for taper, a non-planar face is rejected by design.
#
# ── QA-21.3  Replace Face ───────────────────────────────────────────────────────
#   ▶ Create → Box. MODIFY → "Replace Face". Pick a source face (e.g. the top),
#     then a target face/plane that is tilted relative to it. Tangent Chain = on.
#   ✓ The source face is replaced so the body is now bounded by the target plane
#     (the top becomes slanted); status "Replace Face applied".
#   ✗ "source and target faces must be on the same body" (pick both on one body) /
#     "target face is not planar" (only planar targets supported) / OCC failure.
#
# ── QA-21.4a/b/c  Split Body (plane offset + face/surface tool + N pieces) ──────
#   ▶ Create → Box. MODIFY → "Split Body".
#   ▶ (a) Pick a principal plane, set a non-zero Plane Offset, confirm.
#     ✓ body splits into two bodies offset from the origin (not stuck at 0).
#   ▶ (b) Choose a face/surface body as the splitting tool (body-picker).
#     ✓ body divides into ALL resulting solids (≥2), each a separate timeline body.
#   ✗ only ever 2 halves at the origin → offset/tool not threaded; check console.
#
# ── QA-22.1  Move/Copy Body (non-primitive: extrude/imported/OCC) ───────────────
#   ▶ Sketch + Extrude a body. MODIFY → "Move/Copy Body".
#   ▶ Set dx=10, copy = OFF, confirm.  ✓ the body actually translates +10 X (before

#   ▶ Re-open, dx=10, copy = ON, confirm.  ✓ a SECOND body appears 10mm over; the
