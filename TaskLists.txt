## BUGS

[x] SURFACE_MATERIAL singleton disposed in commitOffsetSurface join path (severity: HIGH)
    File: src/store/cad/slices/assemblyAndSurface/surfaceEditActions.ts (~line 224)
    Issue: `(mesh.material as THREE.Material)?.dispose?.()` is called on a mesh whose material
           is the local SURFACE_MATERIAL singleton. This kills the material for every other
           surface body rendered after the first join-offset, producing black/missing geometry.
    Fix: Guard with `if (!mesh.material?.userData?.shared)` before calling dispose, OR tag the
         local SURFACE_MATERIAL with `userData.shared = true` like the singletons in bodyMaterial.ts.

[x] OCC tool-body handle leaked on boolean throw in commitRevolve (severity: HIGH)
    File: src/store/cad/slices/extrudeRevolve/revolveActions.ts (~line 289)
    Issue: `toolBody` built by `occRevolveWithInstance` has `.dispose()` called only on the
           success branch (line 293). If `performOccBooleanWithInstance` throws, `toolBody` is
           never deleted, leaking a WASM shape on the C++ heap.
    Fix: Wrap `performOccBooleanWithInstance` + `toolBody.dispose()` in a try/finally block.

[x] Stale `features` capture across awaits in commitExtrude (severity: MEDIUM)
    File: src/store/cad/slices/extrudeRevolve/extrudeCommitActions.ts (~line 347)
    Issue: `features` is destructured from `get()` at the top of commitExtrude before multiple
           `await` calls. After any await a concurrent undo/removeFeature can change the live
           state; nextFeatures mutations after those awaits are based on a stale snapshot and
           can resurrect deleted features or mis-index them.
    Fix: Re-read `get().features` after each critical await, or introduce a generation counter
         and abort if the generation changed.

[x] storedEdgeIds + parseOccEdgeSelection duplicated in 3 files (severity: MEDIUM)
    Files: src/store/cad/slices/featureManagement/featureMeshActions.ts (~lines 51, 65)
           src/components/dialogs/solid/FilletDialog.tsx
           src/components/dialogs/solid/ChamferDialog.tsx
    Issue: Identical helper functions are copy-pasted; any OCC edge ID format change (e.g.
           adding a version prefix) must be applied in 3 independent places.
    Fix: Extract to `src/utils/occEdgeUtils.ts` and import from all three call sites.
